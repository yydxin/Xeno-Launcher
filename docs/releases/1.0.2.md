## 液态玻璃组件覆盖修复

之前账号/启动面板及设置卡片有玻璃，但首页可拖拽版本卡、启动按钮、顶栏图标，以及直接使用 Material 容器的其他页面没有统一接入。首页 `CardGrid` 自己创建卡片，仍使用旧半透明背景；独立窗口的对话框/菜单也无法直接取主窗口 backdrop。

- 统一玻璃容器和组件入口：卡片、Surface、按钮/图标按钮、Chip、顶栏、侧栏、Snackbar、FAB、确认框、普通 Dialog、下拉菜单、底部弹层、Tooltip 和前台 Toast。默认主题仍使用原 Material 样式。
- 首页卡片由宿主向 `CardGrid` 注入玻璃卡片表面；拖动和缩放引起位置/尺寸变化时只让玻璃消费者重绘，不重建卡片或 backdrop。
- 主窗口继续从纯壁纸/无壁纸渐变捕获 backdrop；独立窗口从同一壁纸取静态快照，并在各自窗口建立本地 backdrop，不再截取整页内容。文件管理独立 Activity 也补了壁纸层。
- “玻璃应用范围”新增按钮开关，卡片、按钮、对话框与弹出层、顶栏、侧栏可分别切换；调试工坊参数由统一组件读取。
- 保留游戏运行时关闭玻璃、低内存自动降级、低 API 磨砂回退、列表滚动背景录制限帧；不会在滚动或拖拽中每帧读回浮层壁纸。
- 版本卡去重：自动生成且与版本/加载器信息重复的名称改成“Minecraft”，第二行保留版本/加载器；只有真正的自定义描述才额外显示。自定义实例名不变。

## 源码检查与验收边界

静态源码审计记录了 573 个 Compose 目标组件使用点，**未接入入口 0**；四个全屏页面底板及两个显式使用统一渲染的基础按钮表面是有意保留的底层入口。源码中的 `ui/glass/` 统一容器实现、`CardGrid` 宿主注入、`VersionCardText.kt` 和相应测试随 tag 发布。

已完成 ARM64 release 构建、Kotlin 编译、R8、APK 资源表/清单、v2 签名、版本及 41 个原生库的静态校验。此次更正仅替换正式附件和校验值；同版本号安装包不会通过版本号区分新旧，若已下载旧包请核对文件名与 SHA-256。**尚未安装或运行 APK，也没有逐页截图或真机验收**；请实测首页/设置/下载/账号/文件管理、各种弹层、主题/壁纸/深浅色切换、编辑卡片拖拽和低版本降级。视频壁纸在弹层内使用打开瞬间的静帧；携带特殊 caret 的 Tooltip 保留原 Material 外观。当前构建未配置微软 OAuth 客户端 ID 或 CurseForge API Key，相关服务可能受限。

使用 JDK 17、Gradle 9.5.0、AGP 9.3.0、Kotlin 2.4.20、Android SDK Platform 37.2 和 Build Tools 36.0.0。发布 APK 使用 ARM64 预编译 JNI（项目保留来源与校验说明），正式 release 需要维护者自己的签名配置；勿把 JKS/口令放入 Git。参见仓库根目录 [README](../../README.md) 与 [签名配置示例](../../keystore.properties.example)。
